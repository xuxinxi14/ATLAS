# ATLAS 主页衔接与回归
实现与验证：2026-10-28。方案设计：2026-10-27。

## 实现

主页保留遥测矩阵、五领域和最近更新的内容结构，承载在高位玻璃总控面上。复用现有 IndexDeskRig 的玻璃边缘与支撑，不新增美术模型或替换档案资源。真实文字、输入与阅读仍由 DOM 提供。

| 路径 | 动作 | 主页时间轴 |
| --- | --- | --- |
| 主页 → 索引 | 旧内容减弱，保留领域锚点；总控面移近，列表接管 | 1.10s |
| 主页 → 大厅 | 台面先上抬后退，近边获得净空后相机进入；不自动打开档案 | 1.35s |
| 主页 → 新建 | 总控面退让，NEW 空白卡随托盘到位，稳定后交还输入 | 1.40s |
| 主页 → 正文 | 指定同一文件，接入现有抽取、侧插读取器和屏幕激活 | 2.05s 接管；读取器自身 2.25s 时间轴保持 |
| 减少动态效果／无 WebGL | 保留来源和领域信息，约 160ms 淡入，不执行大幅相机运动 | 0.16s |

现有索引与大厅的 1.25s 双向时间轴、档案升起高度、基线材质、五列记忆与背景阵列高度保持。主页交接由同一可反向的进度驱动 DOM 和 Three.js；Esc 从当前状态接续。过场截图层 inert、aria-hidden，移除子节点 ID，结束立即释放，避免重复可交互节点或焦点残留。全局导航保留，窄屏编辑时以工作台内返回入口为主。

关键文件：
- src/home-transit.ts：纯时间轴和可反向时钟。
- src/main.ts：路由来源、页面记忆、焦点与输入隔离、异步编辑请求校验。
- src/scene.ts、src/index-desk-rig.ts：复用玻璃载体及观察相机。
- src/styles/home-transit.css：总控面、交接层与窄屏修正。
- src/studio-tray-rig.ts：主页新建独立阶段，不抽走现有档案。
- src/app/router.ts：全部档案的显式入口与恢复上次索引状态区分。

## 修复的问题

1. 主页最近档案进入读取器后，返回固定指向三维大厅；现在回到实际来源，恢复滚动、条目与有效阅读位置。
2. 主页新建被归类为索引来源；现在显示“返回主页”，新建保持 NEW，首次真实保存后才分配编号。
3. 顶部导航离开编辑页时没有统一记忆草稿、选区和滚动；现在按文件保留，返回时恢复，避免不同文件互相覆盖。
4. 慢载入／旧预览响应可覆盖较新笔记；加入请求版本与目标校验。已离开的保存响应也不能改写另一编辑页面或它的 URL。
5. 保存期间继续编辑时，“放弃修改”的基线错误使用后来未提交的内容；基线改为实际提交的版本。
6. 主页领域入口被旧搜索、类型、状态或仅收藏条件过滤为空；明确点击领域时开始该领域检索，顶部索引与浏览器返回保留原状态。
7. 首页 SVG 圆环同时使用静态矩阵与 CSS 旋转，动画插值带入平移，导致圆弧漂出仪表；静态角度放在外层，动画从纯旋转开始。
8. AI 模板沿用旧分类 coding / creation，实际仓库为 computing / life；模板从仓库领域配置生成，显示名称补齐。
9. 手机工具栏中文被挤成竖排、导航裁切，横屏编辑受最小高度限制不可见；调整窄屏导航、工具栏、身份条与可滚动编辑区，同时修复主页 KPI、最近列表的横向裁切。
10. 主页进入录入时，大厅 HUD 被过场通用规则重新显示；交还大厅 HUD 的规则仅在真正进入大厅时生效。
11. 进入录入时未关闭索引玻璃台，独立载体会残留；录入接管时让原索引台按既有时间轴退让。
12. 正式静态发行包缺少写盘 API，仍显示保存按钮；识别不支持的接口，显示“导出 Markdown”，导出保留未保存状态，文件名与标题／自定义文件名一致。
13. 无 WebGL 编辑既有档案时仍假定模型存在；传递真实能力，显示已有的二维卡座后备图。
14. 重初始化显式释放主页观察姿态和过场节点，开场逐帧对照不接入主页玻璃载体。

## 验证

- npm run typecheck：通过。
- npm test：39 项通过，包括时间轴净空、反向接续、减少动态效果、新建不抽档、来源返回、静态草稿与领域模板。
- npm run build：通过，完整 PWA 静态发行包生成。
- scripts/check-home-transitions.mjs：16 组 Edge / Chromium 浏览器检查通过，无页面异常。覆盖三类主页入口、来源返回与位置、浏览器历史、连续目的地变更、草稿／选区恢复、慢载入、慢预览、跨笔记保存响应、提交后编辑的恢复基线、重初始化，以及 390×844、844×390、暗色减少动态效果、无 WebGL。记录见 [home-transitions/results.json](home-transitions/results.json)。
- scripts/check-home-static.mjs：在正式构建的 preview 上验证主页进入录入、静态导出下载、返回来源及手机导出按钮边界。
- 对应截图在 .tools/home-transitions/；默认画质截图在其 full-quality/ 子目录，功能回归使用隔离浏览器的超级性能设置以降低自动化成本，未修改产品默认画质。

复现浏览器检查时，使用已安装的 Playwright；可通过 PLAYWRIGHT_MODULE 指向模块绝对路径，REVIEW_URL 指向本地服务。静态检查默认 http://127.0.0.1:5192/，可用 Vite preview 提供正式包。

保存、延迟和并发用例拦截 API 响应，不改写真实笔记；静态用例验证浏览器下载，不代表本地 content 已归档。测试浏览器使用独立上下文，不更改用户正在使用的偏好。

手机结果是桌面 Chromium 视口检查，未冒充真实 iPhone / Safari 验收。未上传、部署或改动远程配置。
