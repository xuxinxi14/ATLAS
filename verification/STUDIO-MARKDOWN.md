# Markdown 工作台、阅读界面与性能验证

## 行为与范围

- 正文保留原始 Markdown。实时编辑只在未编辑的位置隐藏标记并呈现样式；光标进入后显示源码。源码、实时编辑和阅读模式共用内容，撤销历史、选区和滚动位置随界面重建保留。
- 支持常用 Markdown / GFM 标题、强调、删除线、列表、待办、表格、代码、链接和图片；支持 `==高亮==`、`[[内部链接|别名]]`、图片嵌入、callout 和 KaTeX 公式。代码块按常见语言着色。内部链接根据标题、路径、ID 或别名匹配；未解析的链接保持可见。待办在编辑模式中可直接勾选。
- 提供 Ctrl/Cmd+S 保存或导出、Ctrl/Cmd+E 切换阅读、Ctrl/Cmd+B/I 强调、Ctrl/Cmd+F 查找、撤销和列表续行。图片粘贴与结构插入使用当前选区；异步上传返回时若已切换档案，不会写入新档案。
- 这不是完整的 Obsidian 应用：插件、图谱、反向链接、画布、同步、笔记嵌入和全部扩展语法尚未实现。不同标题重名时内部链接使用第一个匹配项。
- 发布构建将原始正文放入生成的条目清单，以便离线/静态模式编辑已有笔记；它随站点发布，正文中的 Markdown 注释也可被访问。静态站点不能写入本机文件，只导出 Markdown；导出保留已知的 ID、别名和关联信息，本地接口额外保留自定义 front matter 字段。
- 本地保存先检查目标文件冲突；保留既有 ID、别名、关联和其他 front matter。编译失败时回滚本次写入，并避免覆盖失败期间已被外部再次修改的目标文件。打开笔记后由其他程序修改、随后用户再次保存的并发编辑尚无版本冲突提示。
- 阅读器放大时隐藏同一区域的装饰签名。二维筛选弹窗采用不透明底色，所在层级高于目录，并在矮窗口内滚动。

## 性能

- 编辑器及其代码高亮、公式依赖按需加载。正文输入不再发送整篇预览请求；阅读 DOM 仅在进入阅读模式时生成。状态文字按帧合并更新，行数使用编辑器文档信息；稳定的界面 CSS 变量、焦点隔离和画布透明度不再逐帧重复写入。
- 在此电脑的 Edge 无头测试、1440×900、启用超级性能设置下，用 7,000 个小节、621,890 个 ASCII 字符模拟长笔记：读取约 0.24 秒，粘贴约 0.68 秒，连续输入到下一帧约 11–36 毫秒，切入完整阅读约 0.68 秒。这是合成测试，不代表手机实机或所有笔记。
- 同机 RTX 5060 Laptop GPU、原始画质、1440×900，分别采样约 4 秒：二维索引从约 36 帧/秒到约 39 帧/秒，工作台约 32 帧/秒到约 32 帧/秒。波动较大，不能认为整体 3D 帧率已明显改善；工作台背景约 356 个档案、638 万个三角形仍是主要负载。没有自动降低画质或关闭场景。用户可自行在设置的「渲染画质」选择「性能」，会降低渲染比例并关闭部分光影。
- 同条件下改用现有「性能」预设，工作台采样约 164 帧/秒；无头浏览器可超过显示器刷新率，此数字仅用于比较，不代表用户实际屏幕帧率。该预设使用 80% 渲染比例、较低阴影与折射分辨率，并关闭环境遮蔽和景深。

## 复现与检查

- `npm run typecheck`；在隔离副本中 `npm test`、`npm run build`，避免覆盖工作区已有的内容和生成文件。
- `scripts/check-reading-layout.mjs`：1920×1080、1024×768、390×844、844×390，亮/暗两色；检查筛选窗口背景、实际命中层级和放大阅读器重叠。移动端为桌面浏览器视口模拟，未在真实 iPhone 测试。
- `scripts/check-markdown-editor.mjs`：实时/源码/阅读，表格、公式、callout、语法高亮、内部和页内链接、HTML 清理、撤销、快捷键、待办、图片粘贴、插入结构及跨档案异步上传。
- `scripts/check-home-transitions.mjs`：16 项现有页面衔接、草稿和异步竞态回归。
- `scripts/check-home-static.mjs`：正式静态构建中离线预览、已有笔记原始 Markdown 和已知关联信息导出、离线公式。
- `scripts/check-studio-save.mjs`：必须在 `.tools` 下的隔离副本及专用本地服务执行；检查元数据保留、重名拒绝和编译失败回滚。未向真实笔记写入测试内容。
