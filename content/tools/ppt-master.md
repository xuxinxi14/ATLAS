# PPT-Master 演示文稿工作流指南

## 快速复习

1. **先写 Markdown 结构化大纲**，确定「每页核心结论（Action Title）+ 3 个以内支撑点」，禁止边想内容边调色块。
2. **统一母版与网格**：16:9 画布（`33.867 cm × 19.05 cm`），正文中文使用高可读无衬线体（如 MiSans / 微软雅黑），数字与英文代码使用等宽或几何无衬线体。
3. **单页信息密度上限**：字号不小于 `14pt`，对比色不超过「主底色 + 正文色 + 1 个强调色（如琥珀橙 `#ED821B`）」。
4. **导出前必做三查**：字体嵌入检查、100% 缩放边缘裁切检查、PDF 静态备份导出。

## 适用场景

适用于学术组会汇报、课题答辩、项目路演与课程讲义制作。解决“直接打开空白 PPT 无从下手、前后页排版风格割裂、换电脑字体丢失”三大痛点。

## 前置准备

- 一份已梳理清晰的 Markdown 提纲（参考 [Markdown 基本语法](concept-markdown-basics)）：
  - `#` 对应封面标题
  - `##` 对应章节过渡页
  - `###` 对应单页核心结论（一句话标题）
- 预设色板与单位标志（SVG 矢量格式优先，避免低分辨率带白底 PNG）。

## 操作步骤

### 1. 大纲转页面骨架

将提纲按页拆分，确保每一页标题直接表达结论而非仅写名词：

| 常见弱标题（避免） | 结论型标题（推荐） |
| --- | --- |
| 实验结果分析 | 化合物 A 在 10 μM 浓度下显著抑制细胞迁移（抑制率 68%） |
| 静态资源路径问题 | 统一使用 `BASE_URL` 解析器可彻底消除子路径 404 |

### 2. 版心与三级视觉层次设定

```text
+-------------------------------------------------------------------+
| [分类眉题 / Eyebrow 12pt]                         [页码 / 章节标识] |
| [单页核心结论标题 / Action Title 24-28pt Bold]                     |
| ----------------------------------------------------------------- |
|                                                                   |
|   +---------------------------+   +---------------------------+   |
|   | 左侧数据图表 / 流程图     |   | 右侧关键结论与证据要点    |   |
|   | (占版心 55%~60% 面积)     |   | (不超过 3 条，行距 1.3x)  |   |
|   +---------------------------+   +---------------------------+   |
|                                                                   |
| [底部资料来源 / 备注说明 10-11pt 弱化灰]                          |
+-------------------------------------------------------------------+
```

### 3. 批量检查与导出

- [x] 检查所有图表坐标轴文字是否清晰可读
- [x] 在「文件 → 选项 → 保存」中勾选 **将字体嵌入文件（仅嵌入演示文稿中使用的字符）**
- [x] 同时导出 `.pptx` 与 `.pdf` 双版本备存

## 验证结果

- 在无预装第三方字体的设备上打开 `.pptx`，标题与正文字重不发生回退变形。
- 任意抽取一页，观众可在 **5 秒内** 读出该页核心结论。

## 常见问题与修复

- **问题**：嵌入字体后保存报错或体积暴增至上百 MB。  
  **原因**：使用了不支持子集嵌入的完整 CJK 字体包或 OTF 变体。  
  **修复**：改用标准 TTF 格式字重，或将封面特殊艺术字转为 SVG 矢量形状后再保存。
